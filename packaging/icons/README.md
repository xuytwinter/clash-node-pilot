# Clash Node Pilot icon candidates

Generated by `scripts/generate-icons.py` using Pillow. The three directions are:

- **Orbit**: service nodes around a stable core.
- **Prism**: a routed path and folded prism; selected default for packaging.
- **Compass**: a directional navigation mark for connectivity and control.

`clash-node-pilot.ico` and `ClashNodePilot.icns` are generated from the Prism direction at native multi-size resolutions. Run the generator again after changing the artwork.
